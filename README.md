# Durban Mallu's — Season Stats Tracker

A self-hosted web app for tracking player statistics, results, and performance across seasons for the Durban Mallu's indoor Action Cricket team.

**Live site (games.json):** [kgv808.github.io/dm-stats](https://kgv808.github.io/dm-stats)  
**Live site (Supabase):** [kgv808.github.io/dm-stats/index_supabase.html](https://kgv808.github.io/dm-stats/index_supabase.html)  
**Scorecard archive:** [kgv808.github.io/dm-stats/scorecards/](https://kgv808.github.io/dm-stats/scorecards/)

---

## Tabs

| Tab | What it shows |
|-----|--------------|
| Insights | Season summary, last game result, highlights, ladder standings, head-to-head records |
| Results | Full match history with scores, skins points, and result badges |
| Player Stats | Three sub-tabs: Core Stats (RS, RC, Wkts, Contribution), Batting & Bowling (SR, 7s, Dots, Extras), Dismissals (type breakdown: caught/bowled/run-out/stumped) |
| Pairs & Bowling | Batting pair records by skin, bowling performance heatmap |
| Team Sheet | Pre-match squad selector with auto-generated batting pairs and bowling order |

Covers two seasons: **Spring 2025** (C3 · Fourways Falcons) and **Autumn 2026** (C1 · Hillfox Action Sports).

## Adding a new game

1. Download the PDF scorecard from Spawtz and place it in the correct season folder under `data extraction/pdfs/`
2. Add the game to `data extraction/scorecard_urls.csv`
3. Run the extraction pipeline:
   ```bash
   python "data extraction/run_all.py"
   python "data extraction/aggregate.py"
   python "data extraction/build_games_json.py"
   ```
4. Open GitHub Desktop → commit `data/games.json` → push

The live site updates within ~60 seconds of the push.

## Stat definitions

| Stat | Meaning |
|------|---------|
| RS | Runs Scored |
| RC | Net Runs Conceded (gross runs − wicket credits; can be negative) |
| Wkts | Wickets taken |
| C | Contribution = RS − RC |
| SR | Strike Rate = (RS ÷ balls faced) × 100 |
| 7s | Zone D full hits — ball reaches the back net on the full (6 bonus + 1 physical run = 7 total) |
| DF | Dots Faced — deliveries where the batter did not score |
| DB | Dots Bowled — deliveries where the bowler did not concede |
| Ex | Extras given (No Balls + Wides + Legsides, each worth +2 to batting team) |

RC can go negative — a bowler who takes wickets worth more than the runs they concede ends up with negative RC. This is correct, not an error.

## Tech

- Vanilla HTML, CSS, JavaScript — no frameworks, no build step
- Hosted on GitHub Pages (free)
- **Data layer:** `index.html` reads `data/games.json` (flat file); `index_supabase.html` reads from Supabase (Postgres)
- PDF extraction via Python + pdfplumber
- Fonts: Bebas Neue + DM Sans (Google Fonts)
- Database: [Supabase](https://supabase.com) free tier — project `chswumfxdyjstgsddbhd`
